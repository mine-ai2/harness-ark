# Contributing

This repository is MineAI's fork of [druths/ark](https://github.com/druths/ark).

Before changing anything, read the fork rules and upstream sync process in
[deploy/README.md](deploy/README.md#upstream-sync) — in short: MineAI-specific
code lives only under `deploy/` (plus the `talos-*` workflows), and any change
to `ark/` core must be a candidate for an upstream PR.
